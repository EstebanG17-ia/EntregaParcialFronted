Mini Blog FC Barcelona
Descripción

Sitio web desarrollado utilizando HTML5, CSS, JavaScript y Bootstrap 5, inspirado en Fútbol Club Barcelona. El proyecto presenta información sobre su historia, trofeos y leyendas más importantes del club, haciendo una pagina web con un diseño agradable, organizado y adaptable a diferentes dispositivos.

Objetivo

Aplicar los conocimientos de diseño web responsivo utilizando el sistema de rejillas de Bootstrap, manteniendo buenas prácticas de programación, separación de archivos y una estructura clara para facilitar el mantenimiento del proyecto.

Contenido del Sitio
Inicio

Página principal que presenta el tema del proyecto mediante tarjetas informativas y enlaces a las diferentes secciones del sitio.

Historia del Club

Sección dedicada a la historia del FC Barcelona, incluyendo:

Fundación e inicios del club.
Etapa de supervivencia y representación del catalanismo.
El Dream Team de Johan Cruyff.
La era de Lionel Messi.
El modelo de propiedad basado en socios.

Trofeos

Página que muestra algunos de los títulos más importantes obtenidos por el club a nivel nacional e internacional.

Funcionalidades
Navegación responsiva mediante Bootstrap.
Menú adaptable para dispositivos móviles.
Diseño optimizado para computadoras, laptops, tabletas y teléfonos móviles.
Uso de tarjetas (Cards) para organizar el contenido.
Footer fijo al final de la página cuando existe poco contenido.
Separación de HTML, CSS y JavaScript.
Código limpio, comentado y correctamente indentado.
Diseño visual basado en los colores del FC Barcelona.
Diseño Responsivo

El proyecto utiliza las clases responsivas de Bootstrap para adaptar automáticamente el contenido a diferentes tamaños de pantalla:

navbar-expand-lg
col-12
col-sm-6
col-lg-3
container
row
card

Estas clases permiten que la interfaz se reorganice dinámicamente según el dispositivo utilizado.

Buenas Prácticas Aplicadas
Uso de HTML semántico.
CSS externo para los estilos.
JavaScript externo para la funcionalidad.
Organización del código mediante comentarios.
Correcta indentación y tabulación.
Uso de Bootstrap para reducir código repetitivo.
Compatibilidad con múltiples dispositivos.
